# JobHub — Frontend Web Application

This directory contains the user interface for the **JobHub** platform, built using **React 19**, **Vite**, **Redux Toolkit**, and **Tailwind CSS v4**.

---

## 🚀 Features

- **Candidate Portal**: Browse jobs, view detailed descriptions, filter listings by domain/location/salary, and track application progress.
- **Recruiter Portal**: Dedicated dashboard with analytics charts (Recharts), company onboarding & setup, job publishing, and applicant review workflows.
- **State Management**: Redux Toolkit for global user/job state with Redux Persist for session durability across reloads.
- **Toast Notifications**: Powered by Sonner for real-time user feedback.

---

## 🛠️ Technology Stack

- **React 19**: Modern UI component library
- **Vite**: Ultra-fast build tool and development server
- **Redux Toolkit & Redux Persist**: Global state management
- **React Router DOM v7**: Application routing and navigation
- **Tailwind CSS v4**: Utility-first responsive styling
- **Recharts**: Recruiter analytics dashboard visualizations
- **Lucide React**: Icon library

---

## ⚡ Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview production build:
   ```bash
   npm run preview
   ```

For repository level instructions, backend setup, and environment variables, refer to the [Root README](../README.md).
